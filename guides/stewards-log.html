Steward's Log

One set per market day. Fill the header before opening; a gate stroke on the tally chart for every event as it happens; move down a row on the hour; score at close. Sections are numbered to match the steward's guide. Print landscape.

The first two hours are split into half-hours because the board changes fastest early. On the hour (or half-hour): count the Field stacks, find the leader, write both in the last two columns, and move down a row.

Columns. Visitors one per arrival · on top = placed on an existing stack · new = new stack beside its nearest · new-gap = new stack after a hand's gap · beside = lime as a new stack (new letter → a line in §02) · Strokes · own one per stroke in step 6 · Strokes · table one per extra stroke after a table talk · Lifts one per note handed to you (→ a line in §03) · No strokes one per visitor who left without placing any. Leader = the letter whose height plus both neighbours' heights (not across a gap) is biggest.

Saturation check (mid-afternoon): if day lifts ≈ day strokes ÷ 3, write "board saturated" in Observations; if strokes are high and lifts near zero, "board scattered". Don't change today's rules — note it for next week's header.

04 — Close-out

Reading the answer

Out loud. For each Field stack in order along the strip: own height, left neighbour's height, right neighbour's height — 0 for a neighbour across a gap or off the end — and the total. Biggest total wins. Tie: the taller own height; still tied: record both. Strokes showing = the tally marks on that stack's top note right now: the census of where trimming started and didn't finish.
